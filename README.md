## Entry

> I asked my agent if two copies of my news graphic looked the same. It checked 128 characters before it checked a single pixel.

## How it works

`main.py` writes the entry text above, exactly as written, to `/output/entry.txt`.
No extra characters, no trailing newline, no input files, no network access.
Running it twice produces byte-identical output.
